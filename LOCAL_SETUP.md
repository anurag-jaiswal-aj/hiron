# Hiron Local Development Setup Guide

This guide provides step-by-step instructions for installing, configuring, running, and verifying the complete Hiron platform locally.

---

## 1. Prerequisites

Before starting, ensure your local development machine has the following tools installed:

- **Python**: 3.12+ (or 3.13)
- **`uv` Package Manager**: Install via `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **Node.js**: 20.x LTS+
- **`pnpm` Package Manager**: 9.x+ (`npm install -g pnpm`)
- **Docker & Docker Compose**: Docker Desktop or Docker Engine 24.0+
- **OpenSSL**: Required for local RSA 4096-bit JWT key generation

---

## 2. Installation & Setup

1. **Clone the repository**:

   ```bash
   git clone https://github.com/anurag-jaiswal-aj/hiron.git
   cd hiron
   ```

2. **Initialize local environment file**:

   ```bash
   make setup
   ```

   _This copies `.env.example` to `.env.local`._

3. **Install Python workspace dependencies**:

   ```bash
   uv sync --all-extras
   ```

4. **Install Node.js workspace dependencies**:

   ```bash
   pnpm install
   ```

5. **Generate local RSA 4096-bit JWT keypair**:
   ```bash
   mkdir -p keys
   openssl genpkey -algorithm RSA -out keys/jwt_private.pem -pkeyopt rsa_keygen_bits:4096
   openssl rsa -in keys/jwt_private.pem -pubout -out keys/jwt_public.pem
   ```

---

## 3. Docker Compose Setup

Hiron provides a Docker Compose environment orchestrating PostgreSQL 16 (`pgvector`), Redis, Core API, AI Service, Celery Workers, and Next.js Web App.

```bash
# Start all local containers in the background
docker compose up -d

# Check container status
docker compose ps

# View container logs
docker compose logs -f api
```

To stop containers:

```bash
make down
```

---

## 4. Database Setup

1. **Initialize PostgreSQL database and `vector` extension**:
   ```bash
   make db-init
   ```
   _This runs `scripts/init-db.py` to create the `hiron_dev` database and execute `CREATE EXTENSION IF NOT EXISTS vector;`._

---

## 5. Database Migrations (Alembic)

1. **Apply all pending database schema migrations**:

   ```bash
   make db-upgrade
   ```

   _(Executes `uv run alembic -c apps/api/alembic.ini upgrade head`)_

2. **(Optional) Generate a new autogenerated database migration**:

   ```bash
   make db-migrate m="add_new_feature_table"
   ```

3. **Seed Initial Tenant & Org Admin User**:

   ```bash
   uv run python scripts/seed.py
   ```

   _(Executes idempotent bootstrap creating initial Tenant organization and `org_admin` User)_

---

## 6. Backend Startup (FastAPI Core API)

To run the Core API backend service outside of Docker:

```bash
# Set PYTHONPATH to include apps/api
export PYTHONPATH=apps/api:$PYTHONPATH

# Start FastAPI development server on http://localhost:8000
uv run uvicorn hiron.main:app --reload --host 0.0.0.0 --port 8000
```

- **Interactive API Docs (Swagger UI)**: `http://localhost:8000/docs`
- **ReDoc Documentation**: `http://localhost:8000/redoc`

---

## 7. Frontend Startup (Next.js 14 Web)

To run the Next.js frontend web application locally:

```bash
# Start Next.js development server on http://localhost:3000
pnpm --filter @hiron/web dev
```

- **Local Web Application URL**: `http://localhost:3000`

---

## 8. AI Service Startup (Standalone Microservice)

To run the standalone FastAPI AI microservice locally:

```bash
# Set PYTHONPATH to include services/ai
export PYTHONPATH=services/ai:$PYTHONPATH

# Start AI Service development server on http://localhost:8001
uv run uvicorn ai.main:app --reload --host 0.0.0.0 --port 8001
```

- **AI Service Health Probe**: `http://localhost:8001/health`

---

## 9. Background Worker Startup (Celery)

To run Celery asynchronous task workers locally:

```bash
# Set PYTHONPATH and start Celery worker
export PYTHONPATH=apps/api:$PYTHONPATH
uv run celery -A hiron.core.celery worker --loglevel=info
```

---

## 10. Storage Configuration

Hiron supports both local filesystem storage for development and AWS S3 storage for production:

- **Local Filesystem Storage (Default)**: Uploaded PDF/DOCX resumes are stored in `./storage/<tenant_id>/` on the local disk.
- **S3 Bucket Configuration (Production)**: Configure your `.env.local` or environment variables with:
  ```env
  AWS_REGION=us-east-1
  S3_BUCKET_NAME=hiron-production-resumes
  ```

---

## 11. Verification Steps

To verify that the complete system is running correctly:

1. **Verify Liveness Probe**:

   ```bash
   curl -s http://localhost:8000/api/v1/health | jq .
   ```

   _Expected Response_: `{"status": "healthy", "version": "0.1.0", ...}`

2. **Verify Database Readiness Probe**:

   ```bash
   curl -s http://localhost:8000/api/v1/health/ready | jq .
   ```

   _Expected Response_: `{"status": "ready", "checks": {"database": {"status": "up", ...}}}`

3. **Verify AI Microservice**:

   ```bash
   curl -s http://localhost:8001/health | jq .
   ```

   _Expected Response_: `{"status": "healthy", "service": "ai"}`

4. **Run Full Automated PyTest Suite**:

   ```bash
   uv run pytest
   ```

   _Expected Result_: **339 passed** automated tests (1 skipped).

5. **Run End-to-End Recruitment Workflow Test**:
   ```bash
   uv run pytest apps/api/tests/test_e2e_full_recruitment_workflow.py -v
   ```
   _Expected Result_: 100% green pass across all recruitment lifecycle steps.
