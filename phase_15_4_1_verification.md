## Problems Encountered
1. **Model Constraints:** Initial batch inserts encountered constraint violations (e.g., `ck_candidates_source` and `uq_scores_job_candidate_current`). These were resolved by aligning seed payloads precisely with schema validations.
2. **Missing Columns:** Inherited UUID, `created_at`, and multi-table mapping constraints failed when using bulk insertion shortcuts. Explicit handling of relations via lookup tables in memory (e.g. tracking `job_candidate_id` explicitly for `Score` records) restored functionality.
3. **Query Parameter Limits:** PostgreSQL's 32,767 query argument limit was hit due to `Score` tables having 18 columns (`2000 * 18 = 36000`). BATCH_SIZE was reduced from `2000` to `1000`.
4. **Login Validation:** FastAPI `LoginRequest` expects a JSON body (including `tenantId`), whereas standard OAuth expects a form. Updated Locust authentication to send `json={...}`.
